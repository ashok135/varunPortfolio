# varunPortfolio

Botanical Editorial Video Editor & Creative Director Portfolio.

## Features
- **Hero Intro Experience**: Dynamic hardware-accelerated video intro with scroll lock and smooth color blooming.
- **Responsive Mobile Layout**: Tailored typography and fluid layout for handheld devices.
- **Sections**:
  - Editorial Profile & Philosophy
  - Cinematic Showreel
  - Curated Works with Interactive Category Filtering
  - Experience Journal
  - Direct Inquiry & Contact Form
- **Tech Stack**: React, TypeScript, Tailwind CSS, Lenis Smooth Scrolling, Vite.

## Setup & Running
```bash
npm install
npm run dev
```
